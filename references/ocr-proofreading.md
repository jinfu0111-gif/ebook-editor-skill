# 扫描 PDF → OCR 可重排 EPUB

## 输入诊断与工具选择

先检查 PDF 是否已有文字层及其质量。文字层可靠时提取；只有图片或文字层严重失真时才 OCR。PDF 文字位置通常反映印刷行，不直接代表语义段落。

优先复用可用的 PDF 渲染、版面识别和 OCR 工具，例如 Poppler/PyMuPDF、Tesseract、PaddleOCR 或系统 OCR。按源文语言、横竖排、多栏、脚注密度和设备条件选型。需要重建段落和角标时，保留行/字边框与置信度（hOCR、TSV、ALTO 或等价 JSON）；纯文本 OCR 很难恢复这些位置。

以代表性页验证分辨率、方向和语言设置，再批量处理。300 DPI 是常见起点，不是质量保证。先抽查正文、跨页段落、引文末尾、双脚注页和目录；用样例确定流程后，将同一检查扩展到后续章节。

建立独立项目工作区：源文件、原始 OCR、结构化中间数据、人工修正、打包源、产出和 QA。路径由当前项目配置决定；脚本不能包含作者、书名、个人目录或固定阅读器安装路径。

## 保留证据与修正记录

为每一内容块保留源 PDF 页索引、印刷页码（如能确认）、边框、原始识别文本和修正后的文本。二者页码常不相同；报告同时给出定位依据。校订结果保存为可复用的独立修正表，避免每次重新 OCR 丢失修正。

一种可选记录格式：

```json
{
  "source_page": 12,
  "printed_page": "3",
  "block_id": "page-012-block-04",
  "kind": "paragraph",
  "raw_text": "原始识别内容",
  "text": "对照后内容。",
  "review_status": "source_checked"
}
```

字段可按 OCR 后端调整，不要求转换既有项目。示例数据不对应真实书籍。

## 重建段落和引文

- 以版面位置、首行缩进、栏宽、行距、字体/字形及上下文综合判断正文、标题、引文、诗歌和脚注。
- 去掉页眉、页码时确认其位置和重复模式，避免误删正文中的同名词句或数字。
- 普通正文的印刷行合并为连续段落；诗歌、列表、代码和真实分行保留。
- 页尾/页首有连续段落时跨页合并，保留源页追踪。不能把换页自动变成段落换行。
- 引文结束即使没有显著句号，也可能由段前间距、缩进或栏宽变化确定。下一页开头的作者叙述可能是正文，不能因上页是引文就一并收入 `blockquote`。
- 也不能把所有跨页短句都合并：章节标题、诗行、注释和引文署名可能独立。

## 脚注与句末标点校订

先建立源页角标 → 注释内容 → EPUB 链接的映射。每页重置的注释编号应转换为全书或章节唯一 ID；显示编号可保留源文约定。注释数量相等不能证明位置正确。

角标位置必须对照原页相邻词句，不要把丢失的角标一律放到段末。检查其位于句号前后还是特定名词后；多条脚注分别定位。原稿无法看清时记录待核实，不凭段落含义猜出精确位置。

中文文本中的英文句点和段末缺标点可作为候选清单。逐项回看源页再修正；英文人名缩写、网址、版本号、ISBN、参考文献、诗歌、标题和未结束的跨页句不能批量补 `。`。保留原书真实标点，不强制把所有段落变成完整句。

作者自述与史料引文边界、专名、日期、数字、注释角标和页底小字是重点。不要仅靠“句末有标点”的统计证明 OCR 准确。

## 扩展到全书与交付

样例通过后逐章执行同一规则，记录已审核页和待核实项。对每个含脚注页检查角标及注释；对识别失败、低置信度和布局变化页优先回看原图。若用户要求逐页/逐字复核，实际完成该范围后才能如此标注。

使用标题层级生成导航，正文与引文采用可重排 XHTML。版权页核实出版日期、版次、作者/译者、ISBN；简介另注明来源。源书插图保留清晰版本并提供合理的 alt，不把可识别正文继续作为整页图片交付。

验收包含源页对照、EPUB 包和链接检查、全文疑点审计及阅读器呈现。交付报告列明范围，例如“自动标点审计 + 抽查 12 页 + 全部 27 个含注释页”，而不是未经证据支持的“无错字”。
